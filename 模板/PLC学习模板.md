## 5. 指令与语法

### 5.1 指令速查

| 指令 / 助记符 | 功能 | 关键参数 | 示例 |
| --- | --- | --- | --- |
| `-| |-` (常开) | 条件为 1 时导通 | 操作数 | `%I0.0` |
| `-|/|-` (常闭) | 条件为 0 时导通 | 操作数 | `%I0.1` |
| `-( )` (线圈) | 输出 | 操作数 | `%Q0.0` |
| `TON` | 接通延时定时器 | IN, PT, Q, ET | 延时启动 |
| `TOF` | 断开延时定时器 | IN, PT, Q, ET | 延时停止 |
| `CTU` | 加计数器 | CU, R, PV, Q, CV | 计数包装 |
| `MOVE` | 数据传送 | IN, OUT | 赋值 |
| `CMP` | 比较 | 比较条件 | 温度判断 |
| `CONV` | 数据类型转换 | IN, OUT | INT → REAL |

### 5.2 梯形图示例

```text
网络 1：启保停控制
  I0.0        I0.1        Q0.0
---| |---+----|/|--------( )---
         |
  Q0.0   |
---| |---+
```

### 5.3 SCL 示例

```scl
// 启保停控制
IF "StartButton" AND NOT "StopButton" THEN
    "MotorRun" := TRUE;
ELSIF NOT "StartButton" THEN
    "MotorRun" := "MotorRun";
END_IF;

// 延时启动
"Timer1".TON(IN := "MotorRun",
             PT := T#5S);
"MotorReady" := "Timer1".Q;
```

> [!note] 编程规范
> - 变量使用有意义的英文名称，避免 `M0.0` 直接散落在程序中。
> - 每个网络只做一件事，并写清楚注释。
> - 先画流程/状态图，再写程序。
> - 关键逻辑增加互锁和异常处理。

## 6. 变量表（I/O 分配）

| 名称 | 地址 | 数据类型 | 注释 |
| --- | --- | --- | --- |
| StartButton | `%I0.0` | Bool | 启动按钮（常开） |
| StopButton | `%I0.1` | Bool | 停止按钮（常闭） |
| MotorRun | `%Q0.0` | Bool | 电机运行输出 |
| RunTime | `%MD0` | DInt | 累计运行时间 |
| TempValue | `%IW64` | Int | 模拟量温度输入 |

> [!tip] 地址规划建议
> - 输入 `%I`、输出 `%Q`、保持寄存器 `%M` 分区使用。
> - 为每个变量填写注释，方便后期维护。
> - 模拟量单独规划地址，注明量程与换算公式。

## 7. 程序结构

| 块类型 | 作用 | 本示例中的名称 |
| --- | --- | --- |
| OB1 | 主循环 | `Main` |
| FB | 带背景数据块的功能块 | `MotorControl` |
| FC | 无记忆功能 | `AnalogScale` |
| DB | 数据存储 | `MotorDB` |

调用关系：

```text
OB1
├── FB MotorControl (DB1)
├── FC AnalogScale
└── FB AlarmHandler (DB2)
```

> [!note] 设计原则
> - 一个 FB 只负责一类设备或功能。
> - 使用多重背景减少 DB 数量。
> - 对外接口用 Input/Output/InOut 明确表达。

## 8. 调试与仿真

### 8.1 调试方法

- [ ] 使用 PLCSIM 进行离线仿真
- [ ] 使用监控表观察变量实时值
- [ ] 使用强制表验证输出回路
- [ ] 查看 CPU 诊断缓冲区
- [ ] 检查模块指示灯状态
- [ ] 分段测试：先手动，再自动；先单机，再联锁

### 8.2 故障排查表

| 现象 | 可能原因 | 排查方法 | 解决方法 |
| --- | --- | --- | --- |
| 输入点无信号 | 接线错误 / 公共端接法不对 / 传感器故障 | 用万用表测量端子电压 | 修正接线或更换传感器 |
| 输出不动作 | 程序未导通 / 负载过大 / 输出类型不匹配 | 监控程序状态，测量输出端 | 修改逻辑或增加继电器 |
| CPU 无法下载 | IP 不一致 / 网线或驱动问题 / 保护设置 | 检查网络与在线可访问设备 | 修正 IP 或下载设置 |
| 模拟量数值异常 | 量程错误 / 接线干扰 / 未做换算 | 核对通道配置与换算公式 | 修正量程并增加滤波 |
| 程序运行但设备不动作 | 安全条件未满足 / 互锁未解除 | 逐段监控条件位 | 按流程复位并排查互锁 |
